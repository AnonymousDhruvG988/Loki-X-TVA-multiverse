⚡ PERFORMANCE

A cinematic website still needs to be fast.

The experience is designed around performance-first animation.

🚀 Rendering

🎯 One primary 3D canvas where possible

🧩 Instanced objects for repeated geometry

🖼️ Optimized textures

🎞️ Lazy-loaded heavy assets

🧵 SVG timeline paths

⚡ GPU-friendly transforms

🔄 requestAnimationFrame

💤 Off-screen animation reduction

📱 Mobile quality reduction

🖥️ Controlled device pixel ratio

🎯 Animation

Prioritize:

transform
opacity
SVG stroke animation
GPU-accelerated movement

Avoid unnecessary layout-triggering animations.
